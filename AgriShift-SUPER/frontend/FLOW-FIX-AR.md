# إصلاح انتقالات المينيو — AgriShift

- تم توحيد حركة الستارة الكحلي لجميع روابط القائمة الستة.
- الانتقال بين الصفحات ما زال يستخدم الستارة نفسها.
- الانتقال لأقسام داخل نفس الصفحة (Crop Atlas / Decision Studio / Climate Insights / Our Methods، وغيره) أصبح يُظهر الستارة، ثم يغيّر موضع الصفحة وهي مخفية، ثم يكشف القسم بسلاسة.
- الروابط العادية داخل المحتوى تستمر في التمرير المعتاد، حتى لا نبطّئ استخدام أدوات التحليل.
- لم تُعدّل صور المحاصيل أو اللوجو أو مسارات API أو الـBackend.
- مع إعداد Reduce Motion تُختصر الحركة.
