# AgriShift — Stage A2: Soil Intelligence Screening

## حصل إيه؟

كمّلنا على Stage A1 (Dynamic NASA Location)، **من غير ما نحذف NASA POWER أو حسابات FAO ET0/ETc أو الأربع خطط الحالية**.

أضفنا مدخلات اختيارية للـDashboard:

1. `soil_type`: الرمل/الطمي (Loam)/الطين/غير معروف.
2. `soil_awc_mm_per_m`: **سعة المياه المتاحة للنبات** في التربة، مم مياه لكل متر عمق، لو عند المزارع نتيجة قياس أو تقدير محلي. وجودها يلغي الافتراض الافتراضي لنوع التربة. ليست قراءة رطوبة حالية.
3. `soil_ece_ds_m`: **ملوحة مستخلص عجينة التربة المشبعة** ECe بوحدة dS/m، لو عند المزارع تحليل معمل. ليست ملوحة مياه الري ECiw.

## إيه اللي بيتحسب؟

- `TAW = AWC (mm/m) × root depth (m)` — مليمتر مياه متاحة نظريًا داخل منطقة الجذور.
- `RAW = p × TAW` — الجزء من مياه التربة اللي ممكن يتناقص قبل بدء إجهاد مائي للنبات طبقًا لافتراضات FAO-56.
- `notional_buffer_days = RAW / average midseason ETc` — مؤشر نظري فقط، بافتراض تربة عند السعة الحقلية ونبات بجذور مكتملة وغياب المطر والري وثبات ETc. **ليس موعد رية أو نصيحة ري**.
- `salinity_flag` — مقارنة ECe بحد بداية احتمال انخفاض الإنتاجية طبقًا لجدول FAO-56 للمحاصيل اللي الجدول بيقدم لها حد رقمي: قمح عادي 6.0؛ فول 1.6؛ ذرة 1.7 dS/m. **دوّار الشمس ليس له حد رقمي في الجدول المختار، فمش بنفترض إنه آمن.**

## حدود لازم تفهمها

- لو المزارع اختار نوع تربة من غير قياس AWC، البرنامج يستخدم **منتصف نطاق نوع التربة** من FAO-56 Table 19 (sand 80, loam 155, clay 160 mm/m). الأرقام دي تقديرية مش قياسات لحقل في مصر.
- أعماق الجذور وكسور الاستنزاف `p` مأخوذة من FAO-56 Table 22، غالبًا الحد الأدنى لنطاق جذر نبات بالغ؛ مش عمق الجذور لحظة الزراعة ولا خاص بصنف مصري.
- **مفيش تغيير في ETc أو إجمالي المياه لمجرد تغيير نوع التربة.** نوع التربة بيغيّر سعة تخزين المياه وRAW ومؤشر فترة الجفاف النظري. علشان نحسب تأثير التربة في المياه المطلوبة فعليًا، لازم موازنة مياه التربة/الأمطار الفعالة/توزيع الري.
- إدخال ECe بيضيف إشارات مخاطر. الخطط ذات عدد أقل من تجاوزات الحدود الموثقة تُقدَّم في الترتيب *بعد* اختبار ميزانية المياه؛ لكن **ده فرز بحثي مبدئي، مش شهادة صلاحية زراعة**.
- بيانات NASA اللي عندنا لسنة 2025 تاريخية، وليست توقع موسم 2026/27.

## جرّب بنفسك

من فولدر المشروع:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python start_agrishift.py
```

افتح `http://127.0.0.1:8000/dashboard.html`:

1. خلّي الإحداثيات `30.5,31.5`، اختار **Sand**، واضغط Analyze. هتظهر قيم TAW وRAW.
2. غيّرها إلى **Clay** واضغط Analyze. هتشوف اختلافًا في سعة التخزين لكن احتياج ETc للمحاصيل يفضل كما هو.
3. أدخل `ECe = 4.0 dS/m` **كمثال تعليمي فقط**، ثم Analyze. هتظهر تحذيرات مختلفة للفول والذرة مقارنة بالقمح، ودوّار الشمس يظهر «لا يوجد حد رقمي»؛ لا تستخدم الرقم كمعلومة عن مزرعتك.
4. جرّب ترك نوع التربة Unknown: هتظهر قيمة التخزين Unknown بدل اختراع رقم.
5. لو المزارع عنده AWC موثقة، جرّب إدخال قيمة صالحة، وستظهر كـ`farmer_supplied_awc`.
