# AgriShift — النسخة النهائية ببيانات ECOCROP وتقويم مصر

## ابدأ من هنا

هذه النسخة تضم واجهة AgriShift السينمائية والشات بوت ومحرك القرار الزراعي وملفات المصادر التي أرفقها الفريق. أُضيفت **ملفات بيئية موثّقة لـ12 محصولًا** و**سجلات تقويم زراعي مصرية حسب المنطقة**، دون إنشاء معاملات زراعية من عندنا.

### التشغيل (Windows / macOS / Linux)

```bash
python -m pip install -r requirements.txt
python start_agrishift.py
```

افتح **http://127.0.0.1:8000/**، ثم Dashboard → **Suitability Lab**. أو استخدم `START-WINDOWS.bat` إذا كان Python مثبتًا ومتاحًا.

**الشات بوت** متصل داخليًا في السيرفر لكنه يحتاج متغير `GEMINI_API_KEY` صالحًا على الجهاز أو استضافة السيرفر. **لا تنشر المفتاح في ملفات الواجهة**. طلب NASA الخارجي يحتاج إنترنت؛ استخدم بيانات الدلتا المضمّنة لتجربة يمكن تنفيذها بلا تنزيل جديد، ثم جرّب موقعًا آخر باتصال مباشر قبل العرض.

## ماذا تنفذ النسخة؟

| الأرز والبرسيم | ETc نموذجي فقط؛ الأرز المغمور لا يشمل مياه الغمر والتسرب، والبرسيم الحجازي لا يشمل جميع الحشات. |
| الشات | واجهة عائمة وخدمة داخل السيرفر؛ تشغيل الردود يحتاج المفتاح والإنترنت. |

### ما الجديد بعد ملفات المستخدم؟

- `agrishift_decision/ecocrop_profiles.json`: 12 صورة بيئية بالأسماء العلمية والأكواد الفعلية.
- `agrishift_decision/egypt_crop_calendar.json`: سجلات مصرية مرتبطة بالمحاصيل مع أرقام صفوف Excel، لا تُستبدل بها مواعيد محرك الحساب تلقائيًا.
- `agrishift_decision/calendar_evidence.py`: منطقة صريحة، منع استنتاج المنطقة الجغرافية من GPS دون بيانات مضلعات GIS.
- `agrishift_decision/suitability.py`: فحص 6 محاور محتملة؛ غير المقاس يظل `unknown`.
- `GET /api/calendar-zones`: المناطق المتاحة. `POST /api/crop-assessment`: تحليل الـ12. `POST /api/analyze`: الدورات ومعها `environmental_evidence` تحذيري.
- في Dashboard: اختيار منطقة FAO المصرية ونوع الصرف، وكروت ECOCROP وتقويم ومصادر، وتصدير JSON للنتائج؛ زر قسم Suitability Lab في المينيو والسايدبار.
- نسخة من ملفات المستخدم الأصلية موجودة في `data/evidence/` لتسهيل مراجعة المصدر.

### حدود مهمة يجب أن يعرفها المحكّم

1. **لا يوجد تصنيف علمي كامل لأي نقطة في العالم أو رقم نجاح 90%.** ECOCROP نطاقات عامة على مستوى النوع؛ ليست احتمالات زراعية، والتربة قد لا تكون مقاسة.
2. **تقويم الملف يخص مصر فقط**، واختيار المنطقة **يدوي**؛ لا توجد حدود جغرافية رسمية مدمجة تحدد المنطقة الزراعية آليًا بالـGPS.
3. **إتاحة سجل تقويم للمحصول لا يعني أن مدة نموه أو موعده في نموذج FAO-56 أصبحا معايرين محليًا.** يعرض النظام التاريخ المحلي كتحقق منفصل، ويحذر عند اختلاف مدة النمو المرجعية.
4. البيانات المرفوعة **لا تحتوي سجلات محصول مطابقة للذرة الحقلية أو القطن أو البرسيم الحجازي في تقويم مصر**. الأرز له سجلات بلا منطقة دقيقة وأخرى لمنطقة أخرى، ولا ننسبه للدلتا تلقائيًا.
5. القطن في ECOCROP مُطابق **Gossypium barbadense** تحديدًا وليس كل أنواع القطن، والبنجر السكري مأخوذ من سجل النوع **Beta vulgaris**؛ يجب التأكد من الصنف المحلي. والطماطم في CSV باسمها العلمي القديم `Lycopersicon esculentum`.
6. **المطر الطبيعي السنوي في ECOCROP ليس مانعًا من زراعة محصول مروي.** يُعرض فقط كسياق بيئي للزراعة المطرية. ميزانية المياه المستخدمة في خططنا ليست جدول ري فعلي.
7. لا توجد معايرة ميدانية للإنتاجية أو التكاليف أو أنواع التربة عالميًا، ولا تكامل مباشر مع AppEEARS أو GAEZ.
8. الشات ونقطة NASA live لم يُختبرا خارجيًا في هذا البناء؛ مطلوب تشغيل اتصال فعلي وآمن قبل العرض النهائي.

### المستندات الدقيقة

- `SOURCE-DATA-AUDIT-AR.md`: مطابقة كل محصول، وأسباب الفجوات.
- `SUBMISSION-QA-RESULTS.md`: الاختبارات وحدود الاختبار.
- `data/evidence/`: ملفات المستخدم الأصلية، بما فيها CSV وExcel، بالإضافة لاستخراج JSON للصفوف.
- `tools/build_submission_evidence.py`: إعادة إنشاء صورة ECOCROP وسجلات التقويم من المصادر المرفقة.

**وصف صحيح للمشروع:** Working NASA POWER + FAO-56 *research prototype* with a source-traceable 12-crop environmental screening, not a validated global agricultural advisory service.
