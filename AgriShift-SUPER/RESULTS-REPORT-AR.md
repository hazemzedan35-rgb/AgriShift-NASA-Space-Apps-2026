# AgriShift MVP — تقرير التشغيل والتحقق

**حالة التسليم:** MVP تعليمي/بحثي قابل للتشغيل؛ لم يُختبر كأداة إرشاد زراعي على حقول حقيقية، ولا يحتوي ML مُدرّب.

## البيانات الحقيقية المستخدمة

- NASA POWER Daily Point API — نقطة 30.5°N, 31.5°E، عام 2025، 365 يومًا، 8 متغيرات، لا قيم مفقودة حسب تقرير Stage 1.
- نسخة البيانات هي نفس ملفات الإخراج التي رفعها صاحب المشروع في المحادثة.
- متوسط حرارة الجو: 23.20°C؛ أمطار سنوية: 39.81 mm.
- ET0 السنوي من محرك FAO-56 السابق: 1995.712 mm (مرجعي، وليس مياه الري).

## مثال استكشافي بمدخلات المستخدم

- المساحة = 1 هكتار؛ مياه الري الإجمالية المتاحة لموسمين = 14500 متر مكعب.
- كفاءة الري الافتراضية (يختارها المستخدم) = 75%.
- المحصول السابق = قمح؛ أولوية المزارع = مقارنة متوازنة.
- فصل الشتاء 2026 وفصل الصيف 2027: **تواريخ افتراضية للمقارنة**.
- مدخلات المناخ الخاصة بالخطتين **تستخدم بيانات 2025 النظيرة فقط، وليست توقعًا للمناخ المستقبلي**.

| الخطة | Gross water proxy m³/ha | داخل المياه الإجمالية؟ |
| --- | ---: | --- |
| فول طازج ← دوار الشمس | 14012.68 | نعم |
| فول طازج ← ذرة حبوب | 14358.80 | نعم |
| قمح ← دوار الشمس | 14836.56 | لا |
| قمح ← ذرة حبوب | 15182.68 | لا |

**هذه الأرقام نواتج حسابات المثال فقط، وليست خطة ري حقيقية أو تنبؤًا بالمحصول.** عند تغيير المياه المتاحة إلى 13000 متر مكعب، جميع الخيارات الأربعة تتجاوز الميزانية، كما أثبت اختبار تفاعل الواجهة في المتصفح باستخدام استجابات اختبارية.

## الاختبارات المنفذة

- 60 اختبارًا إجمالًا: 59 ناجحًا و1 متخطّى (اختبار اتصال شبكة خارجي اختياري).
- تشمل التكامل مع API وبيانات NASA ومراحل Kc ومعادلة ETc وتغير الميزانية والكفاءة والمساحة والأولويات.
- واجهة المتصفح عُرضت وتفاعل نموذجها مع استجابات محلية مماثلة للـAPI، بدون أخطاء JavaScript. الوصول المباشر إلى localhost من المتصفح الآلي تم حظره بسبب سياسة البيئة، لكن خادم API اجتاز اختبار HTTP منفصلًا.
- للاختبار على جهازك، شغّل السيرفر ثم جرّب تغيير الميزانية والأولويات في Dashboard.

## ما لم ينجز (بوضوح)

الربط الديناميكي لأي موقع زراعي في العالم، معايرة الزراعة المحلية، تحليل التربة في القرار، SMAP/HLS/GAEZ، ميزانية مياه التربة والأمطار الفعالة، اختبارات ميدانية، وتدريب Machine Learning. كل هذه خطوات تطوير لاحقة، وليست مميزات فعالة في الـMVP.
